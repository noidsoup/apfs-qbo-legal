# Wiki Schema

Page types live under these subdirectories:

- `concepts/` — ideas, architecture, how-things-work
- `decisions/` — ADR-style: context, choice, why
- `entities/` — services, schemas, components, tools
- `guides/` — how-to / runbooks
- `sources/` — external references and links

## Conventions

- Filenames: `kebab-case.md`, H1 = page title.
- Link with `[[wiki-links]]` (e.g. `[[lancedb-retrieval]]`).
- Only write facts backed by commits or repo docs. No secrets.
- Append dated, reverse-chronological entries to `log.md`.
